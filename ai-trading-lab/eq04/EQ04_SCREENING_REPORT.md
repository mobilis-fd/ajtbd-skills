## 1. Итог

**Вердикт по заранее заданному правилу: «Отрицательный результат».**

* Основной тест (IEF, вход на открытии первой сессии после аукциона, выход на закрытии пятой, разница с
  контролями того же месяца и дня недели, вся выборка, 261 событие): **D = −0.3 б.п. на событие**, 95% ДИ
  [−11.6; +14.7], p = 0.50 (M4). Доля событий с D > 0 — 48%.
* Абсолютная доходность после аукциона: +5.8 б.п. брутто за 5 дней — столько же, сколько в контрольных окнах
  (+6.1). При 10 б.п. издержек: −4.2 б.п. нетто и **−7.4 б.п. к денежной альтернативе** (p(>0) = 0.89).
  Безубыточные издержки ≈ 2.6 б.п. за круг против cash — ниже любой реалистичной оценки.
* Эффект был только до 2010 года (+27.0 б.п., p = 0.034 без поправки, Holm по подпериодам 0.10) и в основном в
  2008–2009 гг. В 2010–2019 (−6.2) и 2020–2026 (−11.4) знак отрицательный. На данных, сверенных со вторым
  источником (вход ≥ 2016-11-25), D = −12.7 б.п.
* Не объясняется пересечением с EQ03: окна событий не пересекаются ни с одним окном EQ03 и ни с одним
  переходом месяца. Если убрать из контролей окна конца/начала месяца, D = +5.7 б.п. (p = 0.27) — тоже
  незначимо.
* Рекомендация: EQ04-A закрыть, в портфельный прогон не переводить. EQ04-B (минутные данные) имеет смысл
  только как отдельная гипотеза о внутридневной реакции, не как спасение EQ04-A; данные платные (§9).

## 3. Метод (кратко; полностью — `PROTOCOL.md`)

* Вход: открытие первой сессии строго после даты аукциона; выход: закрытие 5-й сессии. h = 1 и 3 — только
  диагностика, лучший горизонт не выбирался.
* Цены: проверенные дневные скорректированные open/close IEF из v0.3-pre (требование 1); проверка независимым
  пересчётом из сырых данных Yahoo — расхождение 5·10⁻⁹.
* Контроли (требование 5): все 5-сессионные окна с входом в тот же месяц того же года и в тот же день недели,
  без пересечения с окнами исследуемых событий. **Проверено до цен: у каждого события 2–4 контроля, событий
  без контролей нет** (`reports/prereg/prereg_check.json`).
* Издержки 0/5/10/25/40 б.п. за круг; денежная альтернатива — ^IRX на закрытии перед входом × h/252
  (требование 6).
* Статистика (требования 8, 9): ряд D по событиям в порядке времени; метод выбран на синтетике до прогона.
  Ни один кандидат не уложился в порог размера 6.5%; по резервному правилу выбран M4 (циклический блочный
  бутстрэп-t, блок 6), максимальный размер 7.8% (AR(1) φ = 0.3, n = 82), на n = 261 — не выше 6.6%. Метод README
  v0.3-pre (M3) — до 9.0%, t iid — до 12.0%. p-значения M4 считаются приближёнными; на вывод это не влияет
  (основной p = 0.50). Другие методы на основном ряду дают p = 0.50–0.52.

* **EQ03 и конец месяца.** Аукцион 10-летних нот проходит примерно с 8-го по 12-е число, поэтому окна событий
  никогда не задевают последние 5 сессий месяца (окно EQ03) и первые 3 сессии следующего. Результат EQ04 не
  может быть «перенесён» из EQ03. Зато 73% контрольных окон задевают переход месяца, где у IEF исторически
  положительная доходность. Это могло бы занизить D; проверка R2 убирает такие контроли: D = +5.7 б.п.,
  p = 0.27 — по-прежнему не значимо. У 59 событий таких «чистых» контролей нет (они остались в основном тесте).
* **Макро.** Окна событий насыщены публикациями: CPI попадает в 52% окон событий и только в 6% контролей,
  FOMC — 24% против 14%, NFP — 3% против 25%. То есть сравнение с контролями частично смешано с календарём
  публикаций. Подгруппы с CPI или FOMC слегка положительны, без всех трёх публикаций — отрицательны
  (−18.1 б.п.), но ни одна подгруппа не значима. Неблагоприятные события не удалялись.
* **Зависимость.** Окна событий не пересекаются друг с другом; зависимость во времени учтена блочным
  бутстрэпом-t по ряду событий; горизонты не объединялись.
